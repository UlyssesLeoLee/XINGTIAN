# XINGTIAN · 刑天内核透明 Logo 资源包

这是一套透明背景（RGBA）的图标素材，适用于 AI 原生无头 Web 内核的产品品牌、桌面程序、网页与文档。

## 文件结构

- `XINGTIAN_master_transparent.png`：透明母版，正方形安全留白。
- `PNG/`：16、24、32、48、64、96、128、180、192、256、384、512、1024 px 透明 PNG。
- `WebP/`：64、128、256、512、1024 px 无损透明 WebP。
- `Icons/favicon.ico`：网页图标，多尺寸。
- `Icons/favicon-16x16.png`、`favicon-32x32.png`：网页备用图标。
- `Icons/apple-touch-icon.png`：Apple 触摸图标图形资产（透明底）。
- `Icons/android-chrome-192x192.png`、`android-chrome-512x512.png`：Android/PWA 图标图形资产（透明底）。

## 使用说明

所有 PNG/WebP 以及 ICO 均具备透明背景。母版为由图像生成器制作的位图，并不是 SVG 矢量文件。小于 32 px 的图标中精细纹样自然会有所减弱。

浅色背景下建议使用较暗的背景容器以获得更高的对比度；金色主体直接置于纯白背景对比度较低。
